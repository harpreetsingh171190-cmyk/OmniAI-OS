# Contributing to OmniAI-OS

Thanks for your interest! 

1. Fork the repo and create a branch: `git checkout -b feature/my-change`
2. Open the project in Android Studio (Koala or newer) and make sure `assembleDebug` succeeds.
3. Keep changes focused; follow the existing Kotlin code style (`kotlin.code.style=official`).
4. **Never commit API keys, keystores or `local.properties`.**
5. Open a pull request describing what changed and why.

Found a bug or have an idea? Open an issue using the templates provided.
