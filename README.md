# OmniAI-OS

An AI-powered Android application that brings multiple AI services together in one place.

## Features

- AI Chat
- AI Writer
- AI Image Generator
- AI Video Generator
- AI Music Generator
- AI Translator
- PDF Chat
- AI Code Assistant
- Speech-to-Text
- Text-to-Speech
- User Accounts
- Dark Mode
- Favorites & History
