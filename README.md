🤖 OmniAI-OS

OmniAI-OS is an AI-powered Android application designed to bring multiple AI tools and services together in one unified platform.

✨ Features

- 💬 AI Chat
- ✍️ AI Writer
- 🎨 AI Image Generator
- 🎬 AI Video Generator
- 🎵 AI Music Generator
- 🌐 AI Translator
- 📄 PDF Chat
- 💻 AI Code Assistant
- 🎙️ Speech-to-Text
- 🔊 Text-to-Speech
- 👤 User Accounts
- 🌙 Dark Mode
- ⭐ Favorites
- 🕘 Chat & Activity History

🎯 Vision

The goal of OmniAI-OS is to provide a single, convenient Android workspace for everyday AI tasks instead of requiring multiple separate applications.
